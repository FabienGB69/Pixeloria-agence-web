# SEO Skill (Pixeloria)

## Goal
Improve discoverability and search performance for static pages.

## Checklist
- One unique `<title>` per page.
- One descriptive `<meta name="description">` per page.
- Valid heading hierarchy (`h1` once, then `h2...`).
- Semantic sections and internal linking.
- Open Graph and Twitter tags aligned with page content.
- Structured data (`application/ld+json`) when relevant.

## Implementation notes
- Keep copy in French for this project.
- Avoid keyword stuffing; prioritize intent and readability.
- Prefer stable canonical URLs when adding new pages.
