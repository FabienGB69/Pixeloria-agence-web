# Skill: Save Tokens

## Goal
Réduire l’usage de tokens tout en gardant des résultats fiables.

## Rules
1. Lire uniquement les portions utiles de fichier (offset/limit).
2. Préférer `rg` pour localiser avant de lire.
3. Regrouper les éditions d’un même fichier dans un patch unique.
4. Éviter de recopier de gros blocs de code dans les comptes-rendus.
5. Utiliser des sous-agents seulement pour tâches parallélisables et non triviales.

## Output Style
- Résumés courts, orientés actions.
- Mentionner seulement les changements effectués.
