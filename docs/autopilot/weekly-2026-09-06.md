## Résumé exécutif

**⚠️ `main` est CASSÉ (CI rouge) depuis le 2026-09-02 — nouvelle issue P0 #195.**

Le chantier prioritaire du rapport précédent a bien été attaqué : la **migration Next.js 15 (#191)** a été livrée ce cycle (`d2b0dc9` : `14.2.35 → 15.5.25`, plus `a409d60` qui convertit 3 liens internes `<a>` → `next/link` pour la règle lint durcie de Next 15). C'est un vrai progrès sur la seule dette de risque HIGH restante.

**Mais le merge final l'a régressé.** Le merge `b9c9132` (« Merge branch 'main' into … », intégré via **PR #194**) a laissé `package.json` sur l'ancienne plage `next: "^14.2.35"` **tout en conservant le lockfile résolu sur `next@15.5.25`**. Les deux fichiers sont désynchronisés → **`npm ci` échoue systématiquement** (`lock file's next@15.5.25 does not satisfy next@14.2.35`). C'est la commande d'install des **6 jobs CI** et, par défaut, de Vercel.

**Preuve triple, vérifiée ce jour :**
1. État statique `origin/main` : `package.json` = `^14.2.35`, lockfile = `15.5.25` → incompatibles.
2. Repro locale `npm ci --dry-run` → `EUSAGE`, échec.
3. **GitHub Actions run #427** (`main`, head `fa3473a`, merge #194) = **failure** en ~25 s : étape `npm ci` **failure** sur les jobs Lint et TypeScript ; Unit tests / Build / Playwright / Accessibility **skipped**. Run précédent #193 = **cancelled**. Dernier vert = #420 (#192, rapport hebdo).

**Impact :** CI totalement bloquée (aucune PR ne peut passer les checks), et le déploiement Vercel soit échoue pareil, soit **rétrograde silencieusement `next` en 14.2.x** (seule version satisfaisant `^14.2.35`) et **réintroduit les 5 advisories HIGH** que #191 visait à corriger. Dans les deux cas, l'objectif de #191 est annulé en prod.

**Deux réserves de fond persistent, inchangées :**
1. **CSP `'unsafe-inline'` toujours présent** dans `next.config.mjs:35` (`script-src 'self' 'unsafe-inline' …`) — #150 clôturée sans retrait effectif (nuance déjà signalée les 2 derniers cycles).
2. **Cadence en dents de scie** : delivery concentrée le 2026-09-02 (3 PR mergées le même jour), puis **4 jours de silence** (2026-09-03 → 2026-09-06). Et surtout, main est resté rouge 4 jours sans correctif.
