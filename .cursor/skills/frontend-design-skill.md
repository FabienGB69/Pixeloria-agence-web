# Frontend-design Skill

## Objectif
Garantir une qualité visuelle homogène sur l'ensemble des pages.

## Règles
- Respecter les tokens présents dans `:root` de `styles.css`.
- Préserver les contrastes AA pour les textes principaux.
- Éviter les effets non performants (animations lourdes, ombres excessives).
- Vérifier la cohérence des espacements (8px grid).

## Vérification rapide
- Desktop (>= 1200px), tablet (768px), mobile (375px).
- Aucun débordement horizontal.
- CTA principal visible au-dessus de la ligne de flottaison.
