# Skill — UI/UX (Pixeloria)

## Objectif
Maintenir une expérience claire, rapide et persuasive.

## Checklist
- Hiérarchie visuelle : un message principal par section.
- CTA primaire visible au-dessus de la ligne de flottaison.
- Contraste suffisant (texte/CTA/fond).
- Responsive mobile d'abord (320–480 px).
- États interactifs visibles (hover/focus/active).
- Feedback immédiat dans les formulaires.

## Patterns recommandés
- Grilles 2 colonnes desktop / 1 colonne mobile.
- Cartes cohérentes (rayon, ombre, spacing).
- Typographie : max 70 caractères par ligne.

## Tests rapides
- Navigation clavier sur tous les liens/boutons.
- Vérifier qu'aucun contenu ne déborde horizontalement.
